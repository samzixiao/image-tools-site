E-commerce image workflow

E-commerce Image Tools for Product Listings

Turn one product photo into a cleaner set of listing assets. SizeCraft runs the everyday preparation steps in your browser: choose a canvas, keep the product proportionate, add useful dimensions, arrange multiple images, and export a file you can inspect before uploading.

What you can do here

Start with a main product image, then choose an Amazon-style square canvas, an Etsy listing canvas, a Shopify canvas, or a custom size. The editor keeps the source file local to the browser while you crop or fit the photo. You can also build a two-to-nine-image collage from the preview tiles when a single photo does not explain the product well enough.

For product details, add a dimension arrow and enter either centimetres or inches. The paired value is calculated automatically to two decimal places. Multiple image layers, text layers, shapes, privacy covers, and background options help you make a practical asset set without opening a heavier design application.

A repeatable product workflow

  1. Choose the destination canvas.
    Use a preset when the destination has a known ratio; use Custom when the listing brief gives you exact pixels.
  2. Make the product easy to inspect.
    Keep the product large enough to read, avoid cutting important edges, and use Fit with padding when the entire object must remain visible.
  3. Add evidence, not decoration.
    Use cm/in dimension markers, short labels, or a collage tile to answer a buyer question. Keep overlays away from important product details.
  4. Check each export.
    Open the downloaded file, inspect the corners and small text, and confirm that the exported dimensions match the listing workflow.

Common questions

Does this page guarantee a marketplace approval?

No. Marketplace requirements can vary by category, country, and time. Use the editor to prepare the file, then confirm the destination's current rules before publishing.

Can I create several sizes from one photo?

Yes. Upload one main image, select several platform sizes in the editor's batch export panel, and download the base-image versions together. Use the normal Download image button when the composition includes collage or overlays.
