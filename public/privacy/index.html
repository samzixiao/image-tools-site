Privacy information

Privacy at SizeCraft

This page explains the current behavior of the SizeCraft editor in plain language. It is a product note, not legal advice; update it if the site later adds analytics, accounts, advertising, or a server-side upload feature.

Images and browser editing

The current editor is designed to select image files from your device, create a browser preview, and export the result from the page. Images are not intentionally sent to a SizeCraft upload service by the editor described on this site. You should still avoid loading sensitive files on a shared or untrusted computer.

Feedback and external services

The feedback link currently opens a GitHub issue form. GitHub has its own account, privacy, and cookie policies; review those policies before submitting personal information or an image. External links are provided for convenience and are not controlled by SizeCraft.

Future changes

If the project adds analytics, advertising, accounts, cookies, or server-side processing, this page must be revised before those features are released. Check this page again when the product changes.
