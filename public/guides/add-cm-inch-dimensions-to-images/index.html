How to Add cm and Inch Dimensions to an Image

A clean dimension marker can answer a buyer's practical question without turning a product photo into a crowded technical drawing. This guide explains how to add a line, label it with one editable value, and show the converted companion unit.

Why dual-unit labels are useful

Customers do not all use the same measurement system. A shopper may understand inches immediately while a maker, supplier, or international buyer expects centimeters. Showing both units next to the same arrow removes a small but repeated source of confusion. It is especially useful for furniture, clothing accessories, packaging, artwork, handmade goods, and items whose scale is difficult to judge from a photograph.

The marker should support the image rather than compete with it. Use it when the measurement helps someone decide whether the item fits a space, compare it with another product, or understand the proportions of an object. If every edge has an arrow, the main subject becomes harder to read. A single accurate label is usually more helpful than a decorative collection of lines.

Understand the conversion

The basic relationship is 1 inch = 2.54 centimeters. To convert inches to centimeters, multiply by 2.54. To convert centimeters to inches, divide by 2.54. For example, 1.50 in equals 3.81 cm after rounding to two decimal places, and 2.50 cm equals approximately 0.98 in. The displayed pair is a rounded presentation value, so it should not be treated as a more precise measurement than the source.

Pixel length and physical length are not the same thing. A drawn arrow tells the viewer which part of the image the label describes, but the accuracy of the number comes from your real measurement, product specification, or calibrated workflow. If the number is only an estimate, say so in the product description or choose a less authoritative presentation. The editor can format a number; it cannot measure a physical object from pixels alone.

Place the marker where it can be read

Choose a line that follows the measured edge. Keep the endpoints aligned with the two points being described and leave a small gap between the arrow and the object so the line does not disappear into a dark edge. Put the label close enough to feel attached to the marker, but not so close that the digits touch the line. A plain label without a colored background is often enough when the image already has good contrast.

Use a contrasting color only when necessary. Black is a dependable default on a light product background, while white may work on a dark background. If the line and label cross a mixed background, move the marker to a cleaner region or add a restrained styling option. The purpose is legibility, not decoration. Avoid outlines and backgrounds that hide a small product edge or make the label look like a price tag.

Measure the right thing

Decide whether the number describes the outside dimensions, the usable interior, the visible height, or another specific part. A framed print might need the outside frame size, while a storage box may need the interior capacity dimensions. Put a short explanatory note in the listing when the distinction matters. Do not draw a line across a diagonal and call it width unless the number really refers to that diagonal.

For depth, a perspective photo can make the correct endpoint less obvious. Use a second supporting image or a small note if the depth cannot be understood from the front view. For circular items, a diameter marker and a clearly placed label may be easier to understand than two unrelated arrows.

SizeCraft workflow

  1. Load the product image.
    Start with a clean source and choose a suitable marketplace or custom canvas.
  2. Add a dimension marker.
    Create a line for the width, height, depth, or diameter you want to explain.
  3. Enter one value and unit.
    The companion unit is calculated from the same value and displayed with two decimal places.
  4. Adjust line and label separately.
    Move, rotate, scale, or remove the arrow and the text when the composition needs refinement.
  5. Review against the real specification.
    The editor presents your measurement; it does not replace measuring the physical product.

Examples that work well

For a mug, a vertical marker can show overall height while a horizontal marker shows the widest point. For a framed print, one pair of markers can show the outside dimensions and a short note can clarify whether the number includes the frame. For a small accessory, a single width marker may be enough. A collage can compare several variants, but keep the labels consistent so the viewer knows which number belongs to which item.

When an image contains several pieces, use separate markers and place each label near its own line. Do not rely on color alone to distinguish them because color can be lost in screenshots or be difficult for some viewers. Consistent line direction, spacing, and unit format make the comparison easier.

Make dimension labels easy to maintain

Use one decimal policy for a complete image set. Two decimal places are helpful when a converted unit would otherwise lose useful information, but extra precision can suggest a level of accuracy the product does not have. If a specification is 2.50 cm, showing 0.98 in beside it is reasonable; if the source measurement is only an estimate, use a note in the listing rather than implying laboratory precision.

Keep the unit visible in every independent label. A viewer may see a cropped screenshot or a single tile without the rest of the image. When a label is edited, check both the entered unit and the converted value, then rotate or move the label as a group only after the number is correct. A clean, repeatable convention helps buyers compare variants without doing the conversion themselves.

Dimensions in a collage or comparison

If you use several product photos in one board, first decide whether every tile uses the same scale. A dimension arrow on one tile may not be visually comparable with an arrow on another if the photos were taken from different distances. Use the number as the authority, not the apparent line length, and label each tile clearly. If the board is only a planning graphic, say so; do not let a collage suggest that two products were photographed at the same scale when they were not.

Keep the marker and its number above the correct image layer. If the image moves, recheck the endpoint. If the text moves independently, keep it close to the arrow so the relationship remains obvious. Click outside the selected overlay before exporting to confirm that no selection border or delete control is visible in the final file.

Accuracy and accessibility checklist

  • Measure the physical object or use a verified product specification.
  • Use the same decimal convention across all labels.
  • Keep the label close to the line and away from important product details.
  • Use high contrast without a distracting background.
  • Check that arrow endpoints match the measured edge.
  • Review the exported file at the size where a buyer will see it.
