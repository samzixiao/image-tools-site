Social Media Image Tools and Size Workflows

Start with the format the post needs

SizeCraft includes square, vertical, video-cover, and website-sharing presets. The size guide pages explain the intended canvas for Instagram posts, Instagram Stories or Reels, YouTube thumbnails, and Open Graph cards. Choose a preset before composing so the subject and any text have room to breathe.

If you need a set, upload the source once and select several platform cards in the editor's “One image → multiple platform sizes” panel. The quick export makes centered, format-specific base images using the current crop or fit choice, background, rotation, flip, and adjustments. For an annotated composition, finish and export the full composition separately.

A practical social workflow

  1. Pick the first destination.
    Use square for a balanced feed graphic, vertical for a story-style canvas, or thumbnail for a wide video card.
  2. Protect the subject and text area.
    Move the image inside the crop frame, then check that faces, products, and call-to-action text are not close to an edge.
  3. Use a small text system.
    Create short text layers, choose one of the available fonts, and resize the text box rather than forcing a long sentence into a tiny area.
  4. Export and review at phone size.
    Open the result and check contrast, legibility, and whether the crop still communicates the post without its surrounding caption.

Common questions

Should I resize or crop first?

Choose the destination canvas first, then position the crop. Cropping decides what remains visible; resizing the export then gives that visible composition the correct output dimensions.

Will batch export include my text and stickers?

The quick batch panel is intentionally for base-image variants. Use the normal Download image control for the complete edited composition, including text, shapes, stickers, markers, layers, and collage tiles.
