E-commerce image size guide

Etsy Image Size: 2000 × 1600 px

A 2000 × 1600 px landscape canvas is a practical starting point for an Etsy listing image that needs to show the full item and some surrounding context. The 5:4 ratio gives more horizontal room than a square without becoming an extra-wide banner.

Open the 2000 × 1600 editorSee Amazon product size

Make the listing image easy to understand

Show the item at a useful scale and use the extra space to clarify context rather than fill every corner. For handmade goods, a second image can show texture, scale, or packaging; for a primary image, keep the first impression simple and make sure the item is not hidden by text.

Use the editor to crop a source photo, add a shape frame for a detail view, place a dimension marker for physical size, or cover a private address or label before sharing a draft.

Listing image workflow

  1. Choose the landscape canvas.
    Start at 2000 × 1600 so the working area matches the guide.
  2. Position the item.
    Keep the full product visible and use the crop controls to remove distractions.
  3. Add supporting information.
    Use a separate text layer or dimension marker only when it improves understanding.
  4. Review the final file.
    Check edges, text, and color on both desktop and a phone-sized preview.

Common questions

Can I use a different Etsy canvas?

Yes. This is a practical starting preset. Use custom dimensions when your listing brief requires a different ratio.

Can I make multiple listing images?

Yes. Export one edited image at a time, or use the collage board to assemble several views into a single review image.
