Help improve the editor

Tell us what broke or what would help

Good reports make a small tool better quickly. Use the public feedback form to report a bug, request a daily-use feature, or describe a workflow that is harder than it should be.

Open feedback form ↗Return to editor

What to include in a bug report

  1. Name the tool.
    For example: collage upload, shape crop, text layer, or dimension marker.
  2. List the steps.
    Tell us what you clicked and what file or layout you used.
  3. Describe expected and actual results.
    This makes it easier to reproduce the issue.
  4. Remove private data.
    Do not attach faces, addresses, order data, or other sensitive files.

Feature ideas are welcome too

Useful requests are specific: who needs the feature, what repeated task it would simplify, and what a successful result looks like. Requests for practical e-commerce, social, print, and household image workflows are especially helpful.
