About the project

Simple image utilities for everyday work

SizeCraft is a small browser-based toolkit for people who need to prepare an image quickly: crop it to a known canvas, assemble a few views, add a measurement, or hide a private detail before sharing.

What the editor is for

The editor combines common image tasks in one working surface. It supports social and marketplace presets, shape crops, multiple image layers, collage layouts, text layers, dimension markers, privacy stickers, and local export. The goal is not to replace a full design suite. It is to make the small, repeated jobs less frustrating.

SizeCraft is being developed around real user feedback. That is why the project keeps the editor close to the guides: a size page should lead to a useful tool, and the tool should make it easy to report the next problem or request.

How to start

  1. Open the editor.
    Choose a preset or custom canvas.
  2. Load an image locally.
    Adjust the crop and layers in the preview.
  3. Export and review.
    Open the downloaded file before using it in a listing or post.
